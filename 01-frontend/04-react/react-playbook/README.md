# React Playbook

An interactive, self-documenting reference and learning workbench for React. Organized progressively from core foundations to advanced hooks, routing, and practice sandboxes.

---

## 📚 Curriculum Structure

| Level | Topic | Description |
| :--- | :--- | :--- |
| **01** | [`01-basics/`](./src/components/01-basics/) | JSX syntax rules, module exports, `{}` variable interpolation, list & object rendering. |
| **02** | [`02-props/`](./src/components/02-props/) | Unidirectional data flow, prop destructuring, card patterns, and lifting state up with callbacks. |
| **03** | [`03-events-and-forms/`](./src/components/03-events-and-forms/) | SyntheticEvent system, event handlers, and form submission with `event.preventDefault()`. |
| **04** | [`04-hooks/`](./src/components/04-hooks/) | `useState`, `useEffect` lifecycle & cleanups, `useContext`, `useRef`, `useMemo`, and `useCallback`. |
| **05** | [`05-routing/`](./src/components/05-routing/) | Client-side routing with React Router (`<Routes>`, `<Route>`, `<Link>`, and 404 handling). |
| **🧪** | [`playground/`](./src/components/playground/) | Isolated sandbox scratchpad for testing experimental code. |

---

## 🚀 Running the Project

```bash
# 1. Install dependencies
npm install

# 2. Start the interactive development server
npm run dev

# 3. Open in browser
# http://localhost:5173
```
