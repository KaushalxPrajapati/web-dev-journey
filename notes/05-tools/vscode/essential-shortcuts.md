# VS Code Essential Shortcuts & Config

Key keyboard shortcuts and settings to boost development speed in Visual Studio Code.

---

## 1. General & Navigation Shortcuts

- `Ctrl + Shift + P`: Command Palette (Search commands, settings, extensions)
- `Ctrl + P`: Quick Open file by name
- `Ctrl + \`: Split editor pane vertically
- `Ctrl + ` ` (Backtick)`: Toggle integrated terminal
- `Ctrl + B`: Toggle primary sidebar visibility

---

## 2. Editing & Formatting Shortcuts

- `Alt + Up / Down`: Move line or selection up/down
- `Shift + Alt + Down`: Duplicate line or selection down
- `Ctrl + D`: Select next match of current selection
- `Ctrl + /`: Toggle line comment
- `Shift + Alt + F`: Format document (via Prettier or default formatter)
