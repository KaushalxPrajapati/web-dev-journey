# Command Line & Terminal Essentials

Command-line interfaces allow fast, efficient navigation and file management across operating systems.

---

## 1. Directory Navigation

```bash
# Print working directory
pwd

# List contents of current directory
ls

# List detailed contents including hidden files (.gitignore, .env)
ls -la

# Change directory
cd 01-frontend

# Move up one directory level
cd ..
```

---

## 2. File & Directory Management

```bash
# Create new folder
mkdir my-new-project

# Create empty file
touch index.js

# Remove file
rm index.js

# Remove directory and its contents recursively
rm -rf temp-folder

# Copy file
cp source.txt destination.txt

# Move or rename file
mv old-name.js new-name.js
```
